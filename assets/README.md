# Ігрові ассети

Графіка й звуки для майбутніх рівнів і рушія: персонажі, вороги, боси, тварини, предмети, ефекти, тайлсети, інтерфейс.
Кожен пак лежить у своїй папці разом із `manifest.json`, де кожну картинку класифіковано й розкладено на кадри
та анімації. Поле гри вже користується вирізаними спрайтами з `src/ui/sprites/`; цей каталог є повним джерелом,
з якого рушій бере нові спрайти без правок коду.

| --- | --- | --- | --- |

**Sunnyside World** можна поширювати лише як частину навчального курсу і з посиланням на
https://danieldiggle.itch.io/sunnyside (воно є тут і в `sunnyside/LICENSE.md`). Не можна перепаковувати чи продавати
файли, використовувати для NFT і для навчання ШІ. Тож ці файли не можна виносити з гри в окремий набір.

**Не в репозиторії.** Tiny Farm RPG (Maeve Devs) і Village Top Down (Pixeljad) дозволяють використовувати графіку в іграх,
але забороняють викладати самі файли, навіть змінені. Репозиторій публічний, тому їхні картинки й маніфести лежать
окремо, у файлах проєкту EduProstir (`edu-blocks/assets-private/`). Формат той самий.

Музику Ninja Adventure (60 МБ) не додано; звукові ефекти й джингли переведено з WAV в Ogg.

## Формат маніфесту

Типи й функції в [`src/core/assets.ts`](../src/core/assets.ts) (експортуються з `edu-blocks/core`).

```json
{
  "id": "character/ninja-blue",
  "file": "actor/character/ninja-blue/sprite-sheet.png",
  "category": "character",
  "name": "Ninja blue",
  "size": [64, 112],
  "frame": [16, 16],
  "layout": "directions",
  "portrait": "character/ninja-blue-portrait",
  "clips": {
    "walk": { "frames": { "down": [0, 4, 8, 12], "up": [1, 5, 9, 13], "left": [2, 6, 10, 14], "right": [3, 7, 11, 15] }, "fps": 8, "loop": true },
    "attack": { "frames": { "down": [16], "up": [17], "left": [18], "right": [19] }, "fps": 12, "loop": false }
  }
}
```

- **Кадри** нумеруються по сітці рядок за рядком: `індекс = рядок × стовпців + стовпець`, де стовпців = ширина / ширина кадру.
- **Кліп** (`clips`) це анімація: список кадрів або кадри для кожного напрямку, швидкість `fps` і чи повторюється `loop`.
  Якщо дія лежить в окремому файлі (боси, Sunnyside), кліп має свої `file`, `frame`, `size`.
- **`mirror`**: `{ "right": "left" }` означає, що вправо малюємо кадри «вліво», віддзеркалені.
- **`layout`**: `directions` (стовпець на напрямок: униз, угору, ліворуч, праворуч), `side` (вид збоку, для іншого боку
  віддзеркалити), `rows` (рядок на напрямок), `grid` (тайлсет або набір картинок).
- **Шари** (`layer`): селяни Sunnyside складаються з тіла (`human-base`), однієї з шести зачісок і інструментів
  (`human-tools`); малюємо їх один на одному тим самим кадром тієї самої дії.
- **`verify: true`**: кількість кадрів вгадано з картинки (немає підказки в назві чи GIF); варто глянути оком.

Як рушію намалювати кадр:

```ts
import { frameAt } from "edu-blocks/core"

const rect = frameAt(sprite, "walk", "left", msSinceStart) // { file, sx, sy, w, h, flip } або null
```

Основні кліпи для героїв і ворогів Ninja Adventure: `idle`, `walk`, `attack`, `jump`, `dead`, `item` (тримає предмет над
головою), `special1`, `special2`. У босів: `idle`, `walk`, `hit`, `attack`, `charge`, `jump`, `shoot`, `trans` (поява).
У селян Sunnyside: `idle`, `walk`, `run`, `jump`, `roll`, `attack`, `hurt`, `death`, `carry`, `dig`, `axe`, `mining`,
`hammering`, `watering`, `casting`, `reeling`, `caught`, `swimming`, `waiting`, `doing`.

## Як перебудувати

Потрібні Python 3.11+, Pillow і ffmpeg. Паки розпакувати в окремі папки й запустити:

```sh
python3 scripts/assets/build.py \
  --ninja "<…>/Ninja Adventure - Asset Pack" \
  --sunnyside "<…>/Sunnyside_World_Assets" --crops "<…>/FarmingCrops16x16" --farm-kit "<…>/assets" \
  --farm "<…>/Farm RPG FREE 16x16 - Tiny Asset Pack" --village "<…>/TILESET VILLAGE TOP DOWN" \
  --out assets --private-out "<папка поза репозиторієм>" --work "<тимчасова папка>"
```

Тест `src/core/assets.test.ts` перевіряє, що кожна картинка на місці, її розмір збігається з маніфестом, кадри не виходять
за картинку, а пака з забороною поширення в репозиторії немає.
