# Спрайти гри

Кожен файл цієї папки: що він робить на полі, розмір, кадри й звідки його вирізано.
Одна клітинка поля — це плитка 16×16. Повний перелік пака (178 файлів, розміри, кадри, ділянки тайлсета) — у
[`docs/assets/ninja-adventure.json`](../../../docs/assets/ninja-adventure.json). Автори й ліцензія — у [CREDITS.md](CREDITS.md).

## Будова листа персонажа

Листи 64×112 (`ninja`, `robot`, `rover`) мають 4 стовпці, по одному на напрямок: униз, угору, ліворуч, праворуч.
Ряди 0–3: ходьба (4 кадри). Ряд 4: атака. Ряд 5: стрибок. Ряд 6: 0 — лежить, 1 — тримає предмет над головою, 2–3 — особливі пози.
Лист монстра 64×64 (`bee`) має 4 ряди кадрів руху. Лист `grandma` 64×32 має 2 ряди.
